# CCScript 1.337 reference tests

The `.ccs` files in this directory are the reference compiler's own test scripts, taken unmodified from `src/tests` in the CCScript 1.337 distribution by Mr. Accident (`ccscript1337.zip`, published on starmen.net's PK Hack pages). They are here so the conformance tests in `src/` run anywhere the repo is checked out; nothing from this directory ships in the extension.

`scripts/setup-ccscript-compiler.sh` fetches the full distribution, including the compiler itself and its documentation, if you want more than the test scripts.
